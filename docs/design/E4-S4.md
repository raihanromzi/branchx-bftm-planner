# E4-S4 Check-in screen

## Task

At or after a visit, the Admin proves it happened: one photo, GPS if available, an optional note, in a few taps on a phone with a weak connection.

## Priority of content

1. The photo (take or pick)
2. The GPS status
3. "Simpan Check-in"
4. The note
5. Which Kegiatan this is for

## Layout

A full-screen page from the Activity detail (`/kegiatan/[id]/check-in`). The same single column at every viewport, max width 560 px; on desktop it sits in the content area, left-aligned.

```
┌──────────────────────────────┐
│ ←  Check-in                  │
│ SDN 3 Cibinong               │
│ Kam, 20 Nov 2026, 09.00 WIB  │
│ Rina Kartika                 │
├──────────────────────────────┤
│ Foto                         │
│ ┌──────────────────────────┐ │
│ │                          │ │
│ │  [📷 Ambil foto]         │ │  before: two buttons
│ │  [🖼 Pilih dari galeri]  │ │  after: the preview,
│ │                          │ │  with "Ganti foto"
│ └──────────────────────────┘ │
│ Foto tempat atau kegiatan,   │
│ bukan KTP atau buku tabungan.│
├──────────────────────────────┤
│ Lokasi                       │
│ ⌖ Mencari lokasi…            │  → "Lokasi didapat (±12 m)"
│                              │  → "GPS tidak tersedia: izin
│                              │     ditolak" + "Coba lagi"
├──────────────────────────────┤
│ Catatan             0/500    │
│ [                          ] │
│ Jangan tulis nama, NIK, atau │
│ nomor rekening nasabah.      │
├──────────────────────────────┤
│ [      Simpan Check-in     ] │  sticky
└──────────────────────────────┘
```

"Ambil foto" uses `<input type="file" accept="image/*" capture="environment">`; "Pilih dari galeri" the same without `capture`.

## States

- **Photo processing:** after picking, "Menyiapkan foto…" while it is resized on the device; then the preview (max 280 px high) with its final size ("1,1 MB").
- **GPS:** requested on open. "Mencari lokasi…" (spinner, max 15 s) → "Lokasi didapat (±12 m)" (`LocateFixed`, success) or a specific reason (warning, `LocateOff`): "izin ditolak", "tidak merespons dalam 15 detik", "tidak akurat (±450 m)". A "Coba lagi" link retries; the Check-in can be saved anyway.
- **Uploading:** "Simpan Check-in" becomes a progress bar with "Mengunggah 45%"; the page cannot be submitted twice.
- **Saved:** the page shows the result, not a toast: "Check-in tersimpan" with the site badge "Di lokasi (85 m)" or "Di luar lokasi (1,2 km)" / "Di luar lokasi (GPS tidak tersedia)" / "Di luar lokasi (Prospect belum punya lokasi)", and "Kembali ke Jadwal". The Activity is now "Selesai".
- **Upload failed:** "Foto gagal diunggah. Periksa koneksi, lalu coba lagi." with "Coba lagi"; the photo and note are kept in memory.

## Edge cases

- EC29: the page is reachable only from the Activity's day; a direct URL before then shows "Check-in bisa dilakukan mulai Kamis, 20 Nov 2026." with a link back.
- EC27: on a Done or Cancelled Activity: "Kegiatan ini sudah selesai." / "Kegiatan ini dibatalkan." with a link back.
- EC33: as in the GPS states.
- EC34, EC35: the result badge with distance or reason.
- EC37: a non-image: "File ini bukan foto. Pilih foto JPG, PNG, atau WebP." HEIC the browser cannot decode: "Foto HEIC tidak bisa dibuka di browser ini. Ubah pengaturan kamera ke JPG, atau pilih foto lain." Still over 4 MB after resizing: "Foto terlalu besar (maksimal 4 MB). Pilih foto lain."
- EC38: progress and the disabled button, as above.
- EC42, EC43: the two hints, as in the sketch.
- No photo yet: "Simpan Check-in" is disabled, with "Tambahkan foto dulu." under it.

## Copy

As in the sketch and states. Buttons "Ambil foto", "Pilih dari galeri", "Ganti foto", "Simpan Check-in", "Coba lagi", "Kembali ke Jadwal".

## Components and tokens used

shadcn `Button`, `Textarea`, `Progress`, `Alert`. `CheckInSiteBadge`. Client-side resize with `createImageBitmap` and a canvas (`toBlob('image/jpeg', 0.8)`), no library. lucide `Camera`, `Image`, `LocateFixed`, `LocateOff`, `MapPinCheck`, `MapPinX`.

## Accessibility notes

- The file inputs are real `<input>`s with visible button labels.
- GPS status and upload progress are in `aria-live="polite"` regions.
- The photo preview has `alt="Foto Check-in yang dipilih"`.
