# E6-S2 Peta

## Task

The Admin sees where the team's Prospects are and the Stage of each, to plan visits by area, on a phone in the field or a laptop at the branch.

## Priority of content

1. The map with Prospect markers (number = Stage position)
2. Tapping a marker: name, Stage, Funding Officer, link
3. Filters: Funding Officer, Stage
4. The legend
5. The list toggle (mobile)

## Layout

**Mobile (360):** the map fills the viewport height minus the top bar and the bottom nav. Overlaid at the top: a filter button ("Filter", with a count when active) on the left and a "Daftar" / "Peta" segmented toggle on the right, both 44 px, on a white surface with a border. A "Legenda" button at the bottom left. Tapping a marker opens a bottom sheet (not a Leaflet popup) with the Prospect's name, Stage badge, Category, Funding Officer and "Lihat Prospect".

```
┌──────────────────────────────┐
│ Peta                         │
│ [Filter (1)]     [Peta|Daftar]
│                              │
│      (12)        ③           │
│           ①                  │
│   ⑤          (48)            │
│                    –         │
│ [Legenda]               [⌖]  │  ⌖ = centre on my location
├──────────────────────────────┤
│ ▣    ◎     ▦     ⌖     ⋯     │
└──────────────────────────────┘
```

"Daftar" shows the same Prospects (current filters) as the E2-S2 rows, sorted by name.

**Tablet (768):** the same as mobile, with the filters inline at the top instead of a button.

**Desktop (1280):** the map fills the content area. A left panel (320 px) holds the filters, the legend and a scrollable list of the visible Prospects (those in the current map bounds); hovering a list row highlights its marker; clicking a marker highlights and scrolls to its row and shows its details at the top of the panel. No list toggle.

## States

- **Loading:** the map tiles load; the markers area shows a small "Memuat Prospect…" notice at the top.
- **Empty (EC5):** the map shows the default area (the bounds of Jabodetabek, -6.6 to -6.1, 106.6 to 107.1) with a notice: "Belum ada Prospect dengan lokasi. Tambahkan lokasi di halaman Prospect." with "Buka daftar Prospect".
- **No results for filters:** "Tidak ada Prospect yang cocok dengan filter." with "Hapus filter".
- **Error:** "Peta gagal dimuat. Periksa koneksi, lalu coba lagi." with "Coba lagi".
- **Normal:** markers per DESIGN.md "Map markers"; the map fits the bounds of the results on first load.

## Edge cases

- EC6: 2,000 markers are clustered (react-leaflet-cluster on Leaflet.markercluster), chunked loading on.
- EC34: Prospects without location are not on the map; the list view says "34 Prospect belum punya lokasi" with a link to the filtered Prospect list.
- Location denied for "centre on my location": a toast "Izin lokasi ditolak." and the map stays.

## Copy

Title "Peta". "Filter", "Funding Officer", "Tahap", "Semua", "Peta", "Daftar", "Legenda", "Lihat Prospect", "Hapus filter". Legend: one line per Stage number and name (from the default template, plus "– Belum ada Pipeline", "✓ Berhasil", "✕ Gagal").

## Components and tokens used

react-leaflet, react-leaflet-cluster, OSM tiles with the attribution "© OpenStreetMap". shadcn `Sheet`, `ToggleGroup`, `Select`, `Button`. Marker tokens `--stage-1` to `--stage-5`. lucide `ListFilter`, `List`, `Map`, `LocateFixed`.

## Accessibility notes

- Markers have `title` and `alt` text ("SDN 3 Cibinong, Presentasi, tahap 3").
- The list view is the accessible alternative to the map on every viewport (the desktop panel, the mobile toggle).
- Marker colour is never the only signal: the number or symbol inside it carries the Stage.
