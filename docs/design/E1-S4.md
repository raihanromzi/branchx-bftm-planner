# E1-S4 Deactivation with open work, and "Funding Officer nonaktif" labels

## Task

Before deactivating a Funding Officer, the Admin sees what open work is still theirs, and afterwards can find and reassign that work.

## Priority of content

1. The counts of open work, in a sentence
2. The confirm and cancel actions
3. Where the work shows up afterwards

## Layout

**Confirmation:** a dialog on desktop, a bottom sheet on mobile (same content).

```
┌──────────────────────────────────┐
│ Nonaktifkan Rina Kartika?        │
│                                  │
│ 4 Prospect, 2 Pipeline, dan      │
│ 3 Kegiatan mendatang masih atas  │
│ nama Rina Kartika.               │
│                                  │
│ Semuanya tetap atas namanya dan  │
│ ditandai "Funding Officer        │
│ nonaktif" agar bisa Anda alihkan.│
│ Realisasi yang sudah tercatat    │
│ tidak berubah.                   │
│                                  │
│ [Batal]        [Nonaktifkan]     │
└──────────────────────────────────┘
```

On mobile the buttons stack full width, "Nonaktifkan" on top. Counts of zero are left out of the sentence ("2 Pipeline dan 3 Kegiatan mendatang …").

**Labels in lists and details** (Prospect list, Prospect detail, Pipeline detail, Jadwal, Activity detail): next to the Funding Officer's name, a muted label with `UserX`: "Funding Officer nonaktif". In the desktop Prospect table it sits under the name in the Funding Officer column.

**Filter:** the Prospect list's Funding Officer filter gains an option "Funding Officer nonaktif" at the bottom.

## States

- **Loading the preview:** the dialog opens with the sentence replaced by a two-line skeleton; "Nonaktifkan" is disabled until it loads.
- **Preview failed:** "Data pekerjaan Rina Kartika gagal dimuat." with "Coba lagi"; "Nonaktifkan" stays disabled.
- **Confirming:** "Nonaktifkan" shows "Memproses…".

## Edge cases

- EC20: the counts and the labels as above; past Realisasi does not change, as the dialog says.

## Copy

As in the sketch. Filter option "Funding Officer nonaktif".

## Components and tokens used

shadcn `Dialog`, `Sheet`, `Skeleton`, `Button` (destructive variant for "Nonaktifkan"). lucide `UserX`. Token `--muted-foreground`.

## Accessibility notes

- The dialog's title is its accessible name; focus starts on "Batal".
- The label is text with an `aria-hidden` icon.
