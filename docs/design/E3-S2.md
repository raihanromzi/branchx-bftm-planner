# E3-S2 Pipeline Template settings (Pengaturan → Template Pipeline)

## Task

The Admin sets up the Stages and Tasks that a kind of Prospect goes through, usually at a desk; the template editor still works on a phone.

## Priority of content

1. The ordered list of Stages
2. Each Stage's Tasks
3. Save
4. The template name; archive, restore, delete

## Layout

**List page:** rows with the template name, "5 Tahap", "12 Pipeline memakai" and an "Diarsipkan" label when archived. Desktop: a table with the same columns and "Tambah Template". Mobile: rows and a floating "Tambah".

**Editor (mobile, 360):**

```
┌──────────────────────────────┐
│ ←  Ubah Template             │
│ Nama template                │
│ [Sekolah                   ] │
│ Perubahan hanya berlaku untuk│
│ Pipeline baru.               │
├──────────────────────────────┤
│ 1  Identifikasi       ↑ ↓ ⋯  │
│    • Cari data sekolah    ✕  │
│    • Hubungi kepala sekolah ✕│
│    [+ Tambah Tugas]          │
├──────────────────────────────┤
│ 2  Pendekatan         ↑ ↓ ⋯  │
│    …                         │
├──────────────────────────────┤
│ [+ Tambah Tahap]             │
├──────────────────────────────┤
│ [          Simpan          ] │ sticky
└──────────────────────────────┘
```

The number before each Stage is its position (a real sequence). Stage names and Task names are inline-editable inputs. Each Stage has move-up and move-down buttons (44 px), and `⋯` with "Hapus Tahap". Drag handles (`GripVertical`) appear on tablet and desktop in addition to the buttons.

**Desktop (1280):** the editor in an 800 px column; the Stage blocks are separated by borders; "Simpan" and "Batal" sit at the bottom; the header has "Arsipkan" (or "Pulihkan") and, when unused, "Hapus".

## States

- **New template:** one empty Stage ready to fill.
- **Saving:** "Menyimpan…".
- **Loading:** skeleton blocks.
- **Error loading:** "Template gagal dimuat." with "Coba lagi".
- **Unsaved changes:** leaving asks "Buang perubahan?".

## Edge cases

- EC3: removing the last Stage is blocked; saving with none shows "Tambahkan minimal satu Stage." at the top of the list.
- EC21: the note "Perubahan hanya berlaku untuk Pipeline baru." is always visible under the name. "Hapus" appears only when "0 Pipeline memakai"; otherwise only "Arsipkan". An archived template opens read-only with "Pulihkan".
- A Stage name is required (1 to 60 characters): "Nama Tahap wajib diisi." A Task name 1 to 120 characters.
- EC18: the 409 reload message.

## Copy

Titles "Template Pipeline", "Tambah Template", "Ubah Template". Labels "Nama template". Buttons "Tambah Tahap", "Tambah Tugas", "Hapus Tahap", "Simpan", "Batal", "Arsipkan", "Pulihkan", "Hapus". Move buttons' `aria-label`: "Pindahkan Identifikasi ke atas" / "ke bawah".

## Components and tokens used

shadcn `Input`, `Button`, `DropdownMenu`, `AlertDialog`, `Badge`. Drag with `@dnd-kit/sortable` (tablet and desktop). lucide `ArrowUp`, `ArrowDown`, `GripVertical`, `X`, `Plus`.

## Accessibility notes

- Reordering is fully possible with the buttons and the keyboard; after a move, focus stays on the moved Stage and an `aria-live` region announces "Identifikasi sekarang tahap 2."
- Each Task input has a hidden label "Tugas 1 di Identifikasi".
