# E5-S2 Target settings (Pengaturan → Target)

## Task

At the start of a month, the Admin enters each Funding Officer's Target, usually at a desk.

## Priority of content

1. One number input per active Funding Officer
2. The month
3. The team total
4. Save

## Layout

**Mobile (360):**

```
┌──────────────────────────────┐
│ ←  Target                    │
│ [‹  November 2026  ›]        │
│                              │
│ Rina Kartika                 │
│ [ 400             ] rekening │
│ Agus Setiawan                │
│ [ 350             ] rekening │
│ Dedi Pratama                 │
│ [                 ] rekening │
│                              │
│ Total tim  750 rekening      │
│ (1 Funding Officer belum     │
│ diatur)                      │
├──────────────────────────────┤
│ [          Simpan          ] │ sticky
└──────────────────────────────┘
```

**Tablet (768):** the same, max width 560 px.

**Desktop (1280):** a 640 px table: Funding Officer, Target (input, right-aligned, tabular), "Realisasi bulan ini" (read-only, for reference). The team total row at the bottom, bold. "Simpan" under the table.

One "Simpan" saves all changed rows (one `PUT` per changed Funding Officer); an empty input means no Target (not 0).

## States

- **Loading:** skeleton rows.
- **Error loading:** "Target gagal dimuat." with "Coba lagi".
- **No active Funding Officers:** "Tambahkan Funding Officer dulu untuk mengatur Target." with a link.
- **Saved:** toast "Target November 2026 disimpan."
- **Partial failure:** the failed rows show "Gagal disimpan" under the input, the others are saved; "Coba lagi" retries only the failed rows.

## Edge cases

- EC10: "Target harus bilangan bulat 0 sampai 100.000." under the input.
- EC17: inputs show the existing value; saving updates it.
- Copying last month is not offered (backlog E5-S2 #4).
- Changing the month with unsaved changes asks "Buang perubahan?".

## Copy

Title "Target". Unit "rekening". "Total tim", "belum diatur". Button "Simpan".

## Components and tokens used

shadcn `Input` (`inputmode="numeric"`), `Table`, `Button`, `Sonner`. A month stepper (two icon buttons and the month label).

## Accessibility notes

- Each input's label is the Funding Officer's name ("Target Rina Kartika, November 2026").
- The month stepper's buttons are labelled "Bulan sebelumnya" and "Bulan berikutnya".
