# E4-S2 Jadwal, Activity form and Activity detail

## Task

The Admin plans the week's Kegiatan for the whole team (at a desk on Monday morning, or on the phone), and checks today's plan in the field.

## Priority of content

1. The day's Kegiatan in time order: time, Prospect, Funding Officer, status
2. Switching the day or week
3. "Tambah Kegiatan"
4. Filter by Funding Officer

## Layout

**Mobile (360):** a date strip under the top bar (seven days of the current week, each 44 px wide with the weekday and date; today marked with a ring and "Hari ini"; days with Kegiatan have a dot plus a count for screen readers), "‹ ›" to change week. Below it a Funding Officer select. Then the day's Kegiatan, grouped by Funding Officer:

```
┌──────────────────────────────┐
│ Jadwal                       │
│ ‹ Sen Sel Rab [Kam] Jum Sab Min ›
│   17  18  19   20  21  22  23│
│ [Semua Funding Officer     ▾]│
├──────────────────────────────┤
│ Rina Kartika (3)             │
│ 09.00  SDN 3 Cibinong        │
│        Presentasi tabungan   │
│        Terjadwal             │
│ 11.30  Pasar Anyar Blok C    │
│        ⏱ Terlambat           │
│ 14.00  SMPN 1 Bogor  ✓ Selesai│
├──────────────────────────────┤
│ Agus Setiawan (1)            │
│ 10.00  PT Sinar Logistik     │
│                 [+ Tambah]   │
└──────────────────────────────┘
```

Each row opens the Activity detail. Rows are at least 64 px. The list grows with the day; there is no fixed height.

**Tablet (768):** the same, with the date strip and the select on one line.

**Desktop (1280):** a week view: seven columns (Sen to Min), each listing that day's Kegiatan as compact rows: the time and Prospect on the first line, and the full Funding Officer name on a second line in 14 px. The header has the week range "17 – 23 Nov 2026", "‹ Minggu ini ›", the Funding Officer select, a "Hari / Minggu" toggle and "Tambah Kegiatan". The day view on desktop is the mobile list at 800 px width.

**Activity form** (sheet on mobile, dialog on desktop): Prospect (searchable combobox, required), Funding Officer (defaults to the Prospect's), Tanggal (date), Jam (time, WIB, step 15 min), Pipeline (optional; shown only when the Prospect has an open Pipeline, pre-ticked "Kaitkan ke Pipeline Presentasi"), Tujuan (textarea, counter, customer-data hint). "Simpan" / "Batal".

**Activity detail:** a page with Prospect (link), date and time, Funding Officer, linked Pipeline (link with Stage badge), Tujuan, status, then the Check-in section (see E4-S4). Actions: "Check-in" (primary, from the Activity's day), "Batalkan" (menu).

## States

- **Empty day:** "Tidak ada Kegiatan pada Kamis, 20 Nov 2026." with "Tambah Kegiatan".
- **Empty week (desktop):** each column shows "–" and the header keeps "Tambah Kegiatan".
- **Loading:** skeleton rows.
- **Error:** "Jadwal gagal dimuat. Periksa koneksi, lalu coba lagi." with "Coba lagi".
- **Status labels:** "Terjadwal" (muted), "Selesai" (`Check`, success), "Dibatalkan" (`Ban`, muted, line-through on the Prospect name), "Terlambat" (`Clock`, warning).

## Edge cases

- EC2: no active Funding Officers or no Prospects: the form shows "Tambahkan Funding Officer dulu." / "Tambahkan Prospect dulu." with a link instead of the fields.
- EC8: many Kegiatan on one day extend the list; on desktop the week columns grow and the page scrolls.
- EC15, EC36: "Simpan" disabled while saving; a failure keeps the input: "Gagal menyimpan. Periksa koneksi lalu coba lagi."
- EC28: a date in the past is allowed; the form notes "Tanggal sudah lewat. Kegiatan ini akan langsung tercatat terlambat sampai di-check-in."
- EC30: "Terlambat" label.
- Batalkan: "Batalkan Kegiatan di SDN 3 Cibinong, Kam 20 Nov 09.00 WIB?" ("Batalkan Kegiatan" / "Kembali").
- E1-S4: "Funding Officer nonaktif" label.

## Copy

Title "Jadwal". "Hari ini", "Minggu ini", "Hari", "Minggu", "Semua Funding Officer". Form title "Tambah Kegiatan"; labels "Prospect", "Funding Officer", "Tanggal", "Jam (WIB)", "Pipeline", "Tujuan". Buttons "Tambah Kegiatan", "Simpan", "Batal", "Check-in", "Batalkan Kegiatan".

## Components and tokens used

shadcn `Command` (Prospect combobox, server search), `Select`, `Input` (`type="date"`, `type="time"`), `Textarea`, `Sheet`, `Dialog`, `AlertDialog`, `ToggleGroup`, `Skeleton`. `StageBadge`. lucide `ChevronLeft`, `ChevronRight`, `Clock`, `Check`, `Ban`, `Plus`.

## Accessibility notes

- The date strip is a `tablist`-like group of buttons with `aria-pressed` and full labels ("Kamis, 20 November 2026, 3 Kegiatan").
- Status is always text.
- The week view's columns are labelled lists ("Senin, 17 November").
