# E0-S5 Sign-in screen (Masuk)

## Task

The Admin signs in with email and password, on a phone or a laptop, and lands on the page they asked for.

## Priority of content

1. Email and password fields
2. The "Masuk" button
3. The error message, when there is one
4. The product name

## Layout

No app shell. A single column, max width 400 px, placed at the top third of the viewport (not vertically centred, so the keyboard does not cover it on mobile).

**Mobile (360):** 16 px gutter. From the top, 48 px down: "BFTM Planner" (20 px semibold), one line of muted 16 px text, then the form with full-width inputs and a full-width button.

```
┌──────────────────────────────┐
│                              │
│ BFTM Planner                 │
│ Masuk untuk mengelola        │
│ Prospect dan Pipeline tim.   │
│                              │
│ Email                        │
│ [bftm.cibinong@contoh.id   ] │
│ Kata sandi                   │
│ [••••••••••            👁 ]  │
│                              │
│ [          Masuk           ] │
└──────────────────────────────┘
```

**Tablet (768) and desktop (1280):** the same column, 400 px wide, left edge aligned at 96 px from the left on desktop (not centred), on the plain background. No illustration, no hero.

## States

- **Normal:** empty fields, the button enabled.
- **Submitting:** the button is disabled and reads "Memproses…"; the fields stay editable-looking but read-only.
- **Wrong credentials:** an inline alert above the button, in danger colour with `CircleAlert`: "Email atau kata sandi salah." The email stays; the password is cleared and focused.
- **Locked out:** the same alert position: "Terlalu banyak percobaan. Coba lagi dalam 15 menit."
- **Network error:** "Tidak bisa terhubung. Periksa koneksi, lalu coba lagi." Both fields keep their values.

## Edge cases

- EC39: arriving from a protected page carries `?next=`; after success, go there. A `next` that is not a same-site path is ignored, and the Admin goes to the dashboard.
- EC41: the lockout message above.
- Already signed in: redirect to the dashboard without showing the form.

## Copy

Title "BFTM Planner". Lead "Masuk untuk mengelola Prospect dan Pipeline tim." Labels "Email", "Kata sandi". Show-password toggle `aria-label` "Tampilkan kata sandi" / "Sembunyikan kata sandi". Button "Masuk". Errors as above. Empty field errors: "Email wajib diisi", "Kata sandi wajib diisi".

## Components and tokens used

shadcn `Input`, `Label`, `Button`, `Alert`. lucide `Eye`, `EyeOff`, `CircleAlert`. Tokens `--primary`, `--danger`.

## Accessibility notes

- `type="email"` with `autocomplete="username"`, and `type="password"` with `autocomplete="current-password"`.
- The alert has `role="alert"`.
- The button is 48 px high. Enter submits.
