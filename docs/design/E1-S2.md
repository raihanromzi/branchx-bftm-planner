# E1-S2 Funding Officer settings (Pengaturan → Funding Officer)

## Task

The Admin keeps the list of their Funding Officers current, usually at a desk, occasionally on the phone.

## Priority of content

1. Each Funding Officer's name and status
2. Phone
3. Add, edit, deactivate and reactivate

## Layout

**Mobile (360):** title "Funding Officer". A list of rows (not cards), 64 px high: name (16 px, 500) with the phone below (14 px muted, as a `tel:` link), and on the right a status label for inactive ones and a `⋯` menu (Ubah, Nonaktifkan / Aktifkan lagi). A floating "Tambah" button (56 px, accent, `Plus` icon with the text "Tambah") sits above the bottom nav, bottom right.

```
┌──────────────────────────────┐
│ Funding Officer              │
├──────────────────────────────┤
│ Rina Kartika              ⋯  │
│ 0812-3456-7890               │
├──────────────────────────────┤
│ Agus Setiawan             ⋯  │
│ 0813-1122-3344               │
├──────────────────────────────┤
│ Dedi Pratama  [Nonaktif]  ⋯  │
│ 0857-9988-7766               │
│                   [+ Tambah] │
└──────────────────────────────┘
```

**Tablet (768):** the same list, max width 640 px.

**Desktop (1280):** a table with columns Nama, Telepon, Status, and an actions column (Ubah, Nonaktifkan). The header row has "Tambah Funding Officer" on the right. Active first, then inactive, sorted by name.

The add and edit form is a dialog on desktop and a bottom sheet on mobile, with Nama and Telepon and "Simpan" / "Batal".

## States

- **Empty:** "Belum ada Funding Officer. Prospect, Pipeline, dan Kegiatan ditugaskan ke Funding Officer, jadi tambahkan tim Anda dulu." with the "Tambah Funding Officer" button.
- **Loading:** five skeleton rows.
- **Error:** "Daftar Funding Officer gagal dimuat." with "Coba lagi".
- **Normal:** as above; up to 15 rows, the longest name 100 characters, which wraps.

## Edge cases

- EC11: an invalid phone shows the server's message under the field: "Nomor telepon tidak valid. Contoh: 0812 3456 7890".
- EC15: "Simpan" is disabled while saving.
- EC18: a 409 shows "Data ini sudah diubah. Muat ulang untuk melihat versi terbaru." with "Muat ulang".
- Deactivate without open work: a simple confirm ("Nonaktifkan Rina Kartika? Ia tidak bisa ditugaskan pekerjaan baru."). With open work, see E1-S4.

## Copy

Title "Funding Officer". Buttons "Tambah Funding Officer" (desktop) / "Tambah" (mobile FAB), "Ubah", "Nonaktifkan", "Aktifkan lagi", "Simpan", "Batal". Labels "Nama", "Telepon". Status label "Nonaktif". Phone is displayed as "0812-3456-7890" (local format), stored `+62`.

## Components and tokens used

shadcn `Table`, `Dialog`, `Sheet`, `DropdownMenu`, `Input`, `Label`, `Button`, `Badge` (outline, muted). lucide `Plus`, `Ellipsis`, `UserX`.

## Accessibility notes

- The `⋯` button has `aria-label="Aksi untuk Rina Kartika"`.
- The status "Nonaktif" is text, not only a colour.
- The phone input is `type="tel"`, `inputmode="tel"`.
