## Design review

The builder reviewed 48 screenshots (every state at 3 viewports, plus dark). The main conversation re-checked mobile editor-top and desktop list against `docs/design/E3-S2.md` and the anti-slop list.

Fixed during the review:
- a hydration mismatch on `/baru`;
- a stale "no Stages" error that stayed visible after the next save;
- Task inputs that were 4 px out of line;
- "Pulihkan" made the primary button.

## Accepted deviations

- **Touch reordering on mobile:** tapping the move buttons, because the design puts drag handles on tablet and desktop only. dnd-kit's pointer sensor also lets a finger drag the handle from 768 px; that touch drag is not covered by an automated test.
- **Task reordering:** a ⋯ menu on each Task. The criterion asks for it; the design file only shows ✕.
- **Archive and delete placement:** below "Tambah Tahap" on mobile.
- **Copy the design did not give:** the toasts, dialog bodies and empty-state copy.
- **`instant = false` on `/pengaturan/template-pipeline/[id]`:** the same shell workaround, still a follow-up for E2-S4.
- **Unsaved-changes guard:** the sidebar and bottom-nav links don't trigger it; the back link, Batal and `beforeunload` do.

New dependencies: `@dnd-kit/core` 6.3.1, `@dnd-kit/sortable` 10.0.0, `@dnd-kit/utilities` 3.2.2.
