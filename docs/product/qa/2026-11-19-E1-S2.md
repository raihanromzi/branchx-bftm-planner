- The focus ring is a 2 px solid outline with a 2 px offset on Input and Button.

## Design review

The builder reviewed screenshots of 10 states at each viewport. The main conversation re-checked mobile normal, desktop normal and the mobile field error against `docs/design/E1-S2.md` and the anti-slop list: rows and a table, no cards, no gradients, no blur, text labels for status. One fix came out of the review: the desktop row actions were made accent-coloured so they read as actions.

## Follow-up closed

The focus ring on the shared `Input` and `Button` (from E0-S5) is fixed in `src/components/ui/`. The sign-in form's local workaround is removed, and the E0-S4 and E0-S5 tests still pass.

## Accepted deviations

- **Test cleanup in `tests/e2e/support/global-setup.ts`:** it deletes only Funding Officers whose names end with the e2e marker, and it refuses to run against `neon.tech` hosts.
- **Tablet layout:** a list rather than a table at 768 px, per the design file.
- **Status cell:** the desktop Status column shows a muted "Aktif" for active Funding Officers.
