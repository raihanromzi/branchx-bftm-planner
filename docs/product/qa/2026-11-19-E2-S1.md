## Code and security review

- **Finding, fixed before verification:** Category was required, which contradicted `docs/design/E2-S3.md` and the brief (only the name and the Funding Officer are required). It is now optional: the migration was regenerated before any commit, and the tests and `api.md` were updated.
- **Security:** no findings. The search term is a bound parameter with LIKE wildcards escaped; every query parameter is validated (UUID, page bounds, search length); no account-holder fields exist (ADR 0001).
- **Accepted decisions:** `archived=1` includes archived rows together with active ones; matching names exclude archived Prospects and are capped at 20; `archiveProspect` is the single archive entry point, ready for E3-S3 and E4-S1.
