2. **Prospect identity (criterion 1).** Reuse the detail component for a different Prospect ID while its requests are delayed. Expected: new-ID loading state and no old mutation controls. Actual: unkeyed state retains the prior Prospect. A keyed route screen is the proposed fix; regression must verify it.
3. **Archive preview (criterion 4, EC18).** Open archive preview, then change the Prospect and add a future Activity elsewhere. Submit with the old version and reload after 409. Expected: refreshed version and cancellation count, with archive disabled while refreshing. Actual: version updates but the old preview remains mounted.
4. **Map viewport (criterion 1).** Change location elsewhere, then reload detail data after a conflict. Expected: marker visible at the new location. Actual: Marker props update but MapContainer retains its initial center.
5. **Map accessibility.** Reach the mini-map using assistive technology or keyboard. Expected: accessible map label and actionable OpenStreetMap attribution. Actual: `inert` removes the label and attribution from interaction/accessibility.
