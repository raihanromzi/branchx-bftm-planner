## Design review

The builder reviewed every state at all 3 viewports with realistic mocked rows. The main conversation re-checked mobile normal and desktop normal against `docs/design/E2-S2.md` and the anti-slop list: rows separated by borders, a dense desktop table with right-aligned tabular figures, colour only from the accent and the Stage tokens, and status always given as text.

Fixed during review:
- desktop column widths rebalanced so "Pembukaan Rekening" fits;
- the Lokasi column widened;
- the desktop inactive label shortened, with the full text kept for screen readers;
- the search text set to 16 px on tablet;
- no bare "0 Prospect" in the empty states.

## Accepted deviations

- Native `<select>` filters styled as chips: the phone's own picker opens, and each has an `aria-label`.
- The archive toggle is a button.
- The Stage badge wraps inside itself rather than truncating.
- `export const instant = false` on the placeholder `/prospect/[id]` page works around a shell issue: BottomNav calls `usePathname` outside Suspense. This is recorded as a follow-up for E2-S4.
